# Bundled Font Licenses

React Speedrun Tools bundles the following font families. Each family keeps its
upstream license file in its folder.

| Family | License | Upstream |
| --- | --- | --- |
| Inter | SIL Open Font License 1.1 | <https://github.com/rsms/inter> |
| Poppins | SIL Open Font License 1.1 | <https://github.com/itfoundry/Poppins> |
| Plus Jakarta Sans | SIL Open Font License 1.1 | <https://github.com/tokotype/PlusJakartaSans> |
| Roboto | Apache License 2.0 | <https://github.com/googlefonts/roboto-2> |

The fonts are redistributed unmodified as part of the extension and are copied
into user projects only when the user runs **Add A Font**.
